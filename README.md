# Artist Alley Tally

A sales tally for artist alley tables. Add your products and inventory, first. Then on the orders screen, tap what a customer is buying, tap how they paid, and it's logged. At the end of the day it shows what you made, where the money is (cash, Venmo, Zelle, card), what sold, and your best sellers.

It runs in a browser on a phone, tablet or laptop, installs to the home screen like an app, and keeps working with no wifi. Everything is saved on the device. There is no account, no server and no running cost.

## Try it on your local computer

You need [Node.js](https://nodejs.org) installed. Then, in this folder:

```bash
npm install
```

```bash
npm run dev
```

Open the address it prints (usually http://localhost:5173). Choose "Try with sample items" to play with pretend items.
 
## Installing it like an app

Open the link, then:

- **iPhone or iPad:** in Safari, tap Share, then Add to Home Screen.
- **Android:** in Chrome, open the menu and tap Install app.
- **Laptop:** in Chrome or Edge, click the install icon at the end of the address bar.

iPhone users can add it to the home screen. Safari can clear data for sites that are only opened in a tab and then left unused for a few weeks; installed apps are not affected.

## Where the data lives

The data is stored on the device, in the browser's own storage. Nothing is uploaded. That also means:

- A phone and a laptop each have their own separate data.
- Clearing the browser's site data erases it.
- Using incognito mode or private browsing will not save data. 
- **More → Save backup** makes one file with every item, photo and sale.
